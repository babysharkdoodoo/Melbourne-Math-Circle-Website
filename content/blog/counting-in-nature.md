Counting repeated features is one way to describe a plant or animal. Record what you observe before looking for a pattern.

## Compare counts
Count the petals on several flowers of the same kind. Write each count in a table. Are the counts identical, or do they vary? A pattern in a few examples is an observation to investigate, not a rule for every flower.

## A number pattern
The Fibonacci sequence begins 0, 1, 1, 2, 3, 5, 8, 13. Each new term is the sum of the previous two. For example, 5 + 8 = 13 and 8 + 13 = 21. Some plant arrangements can be studied using this sequence, but a petal count alone does not explain how a plant grows.

## Try it
Sketch a fallen leaf and count a repeated feature, such as pairs of veins. Label what you counted so someone else can check your result. Then write the next three terms after 13 in the Fibonacci sequence.

The next terms are 21, 34, and 55.
